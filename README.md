# WorkDo — ERP-Платформа управления бизнесом полного цикла

Репозиторий содержит главную страницу (лендинг) ERP-платформы WorkDo.

**WorkDo** — это платформа управления бизнесом полного цикла для трёх индустрий:
охранные предприятия, строительные компании, яхт-клубы и марины.
Управление персоналом, объектами, финансами и отчётностью — в единой платформе, «одно окно для всех задач».

---

## Что показывает лендинг

Главная страница состоит из секций:

| Секция | Содержание |
|---|---|
| **Герой** | ERP-Платформа управления бизнесом полного цикла. «Управляйте бизнесом из одного окна» + кнопка «Попробовать бесплатно» |
| **Платформа в цифрах** | 150+ решений в одной платформе · до 10 000 объектов и сотрудников · до 5 000 объектов · 99,9% Uptime инфраструктуры |
| **Возможности платформы** | Управление персоналом, GPS-контроль, финансовый учёт, бизнес-аналитика, безопасность, API и интеграции |
| **Преимущества платформы** | Управление филиалами, мобильное приложение, сокращение времени на учёт, 7 лет развития, безопасность данных, интеграция с 1С и банками |
| **Три мануфактуры** | Готовые решения: охранная, строительная, водная (яхт-клубы и марины) |
| **Ваши данные под защитой** | Резервное копирование, изоляция данных, готовые интеграции, соответствие 152-ФЗ |
| **Тарифы** | Базовый (4 990 ₽/мес), Профессиональный (9 990 ₽/мес), Корпоративный (индивидуально) |
| **CTA** | Персональная демонстрация. «Попробовать бесплатно» |

Анимации, градиентные заголовки и счётчики сделаны без внешних библиотек анимаций —
на Framer Motion и встроенных компонентах страницы (`Counter`, `RevealLine`, `RevealWords`, `MagneticLink`).

## Технологии

- **Next.js 16** (App Router, React Server Components + клиентские компоненты)
- **React 19**
- **Tailwind CSS v4** (PostCSS)
- **Framer Motion** — анимации
- **lucide-react** — иконки
- **TypeScript** (strict)

---

## Структура проекта

```
.
├── next.config.ts          # конфигурация Next.js
├── postcss.config.mjs      # PostCSS + Tailwind v4
├── tsconfig.json           # TypeScript (алиас @/* → ./src/*)
└── src/
    └── app/
        ├── page.tsx        # ★ ГЛАВНАЯ СТРАНИЦА (весь лендинг в одном файле)
        ├── layout.tsx      # корневой layout + SEO-метаданные (title, description)
        └── globals.css     # Tailwind + базовые стили
```

Весь лендинг находится в одном файле `src/app/page.tsx` — компоненты страницы
определены локально в нём же.

## Запуск

Требования: **Node.js 18+** и npm.

```bash
# 1. установить зависимости (только при первом запуске)
npm install

# 2. собрать проект
npm run build

# 3. запустить на http://localhost:8000
npm run start
```

Для разработки (автоперезагрузка):

```bash
npm run dev        # http://localhost:3000
```
